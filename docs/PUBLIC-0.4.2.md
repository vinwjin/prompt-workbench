# 0.4.2-beta.1 公开更新范围

2026-10-27，整合本地dev.24已验收的实现，公开候选固定为0.4.2-beta.1，不复制本地提交历史。

- 账号连接：Grok／ChatGPT／WorkBuddy／Antigravity内置授权、目录与主动图文调用，当前模型选择独立于默认值。凭据DPAPI保存，业务JSON不带令牌。Antigravity公开包不内置其他客户端的OAuth注册信息，需维护者提供自己的PW_ANTIGRAVITY_OAUTH_CLIENT_ID和PW_ANTIGRAVITY_OAUTH_CLIENT_SECRET；账号须已有官方启用项目。
- 个人收藏：来源图独立附件、视频保留原链，失败可重试；个人页和广场共用大图瀑布流，管理功能保留。
- 广场／采集：SQL摘要分页、组合筛选、规则与人工修正、明确发起的模型建议、链接队列／作者预览和断点。未知自动访问权限来源维持仅原站／有权文件导入，含mother和OpenNana系列；不附第三方正文／媒体。
- 数据和效率：分类容量、JSON业务备份与手动SQLite一致性快照、状态revision复用、Ctrl+K页面／模板搜索、200卡片分段继续提示。

快照只含数据库（含加密凭据），不包含外部素材；跨电脑／Windows用户迁移仍需重新登录。完整备份应保存data目录，保留私人素材。升级前正常关闭服务并备份完整data，新包不得覆盖旧data；回退保留备份，新版本号不代表所有账号权限／内容质量验收。

生产零第三方依赖、Node24+、Windows优先，不开放公网、不自动发送生成、不自动重试计费请求。界面和测试使用合成数据。公开包不携带本机配置／data／work／日志／研究仓库／私人截图／OAuth注册秘密。

验证执行中：check、Node24单元测试、发布白名单、源码包中文空格路径空数据启动、模拟桌面手机UI、旧公开后台草稿与正常启停；最终证据与局限会在STATUS更新。
