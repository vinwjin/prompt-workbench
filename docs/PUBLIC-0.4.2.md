# 0.4.2-beta.1 公开更新与升级

2026-11-04，基于本地0.4.2-dev.41（8b3be3b）整理公开发行，替代此前仅整合dev.24的草稿候选；未复制本地开发历史或私人资料。Windows优先、Node24+、生产零第三方依赖；这是beta预发布，不是安装器。

## 主要变化

- 模型连接：直接使用已安装的llama.cpp，多模型目录、保存默认、工作台快捷切换；不包含或下载引擎／模型，不改其他客户端配置，不接管外部进程。用户须在连接高级设置提供自己的引擎和GGUF目录。目录读取／启停成功不代表模型生成质量。
- AI图像合成台：本地ComfyUI工作流导入、配套与参数、参考图组合、预览、下载、历史与主动另存目录；在线OpenAI兼容／Gemini生图。普通聊天模型不保证生图；使用自有ComfyUI安装、对应节点和模型，含LocalQwen类工作流不保证普通安装即兼容。账号订阅登录不冒充图片API权限。
- 参考素材：脸部、服装和姿势独立参考库，用户手动同步与选择，按需缓存；不捆绑第三方原图或目录数据。选中的参考图仅在用户发起对应生成时发送到所选服务；外部内容不因本项目MIT许可而取得再分发权。
- 提示词／采集／广场：个人原图独立收藏、卡片与整理、链接与作者确认采集、组合筛选和人工修正、SQL摘要分页和按需正文、有界滚动。41项来源登记不等于全部可同步，未知权限仍只提供原站／有权文件导入。
- 数据与使用：数据中心、业务备份／一致性SQLite快照、任务图片外置、容量与缓存管理、状态复用、快捷导航、暗色画廊布局。大JSON仍使用内存，需关注磁盘容量；本版未承诺完整手机支持。
- 账号：Grok／ChatGPT／WorkBuddy／Antigravity授权、模型目录及用户主动调用。登录成功、套餐权限、模型目录和实际生成是不同验收层。Antigravity需自行提供合法OAuth注册：PW_ANTIGRAVITY_OAUTH_CLIENT_ID及PW_ANTIGRAVITY_OAUTH_CLIENT_SECRET，并完成服务官方项目启用；包内不含第三方注册秘密。

## 从旧版升级

1. 先在旧页面保存草稿并正常关闭，确认端口已释放；新版页面连旧后台时保留保存／正常关闭入口，启动器拒绝静默复用旧版。
2. 备份一致性的数据库、私人素材及配置。SQLite快照不包含外置素材；完整回滚不能只留数据库。Windows DPAPI凭据不能跨用户直接恢复。
3. 将新源码包解压到独立目录。旧data不要被空目录覆盖；停机后迁移私人数据。公共缓存可重新读取，无需反复复制。
4. 使用Node24和新目录启动器；分别核对程序、/health与页面版本0.4.2-beta.1。先验证原资料与模型连接，再由用户发起生成。
5. 回退使用原程序和升级前完整备份；不要让旧程序直接改写已迁移数据库。发布tag和附件不可覆盖，后续修正另发版本。
